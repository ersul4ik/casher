# Шорткат на iPhone: пуш банка → бот

Читать чужие уведомления на iOS может только приложение «Быстрые команды» (Shortcuts) —
через триггер автоматизации «Когда я получаю уведомление». Нативное приложение так не умеет,
поэтому этот шаг делается руками на телефоне один раз.

Нужен iOS 27 или новее: именно там появился триггер по уведомлениям с фильтрами
по Title / Subtitle / Message. Проверить версию: **Настройки → Основные → Об этом устройстве**
(Settings → General → About).

«Быстрые команды» (Shortcuts) — отдельное приложение с иконкой из разноцветных квадратиков,
а не раздел настроек. Открыть проще всего свайпом вниз по домашнему экрану и поиском по слову
`Shortcuts`. Если приложение удалено — поставить заново из App Store.

**Что подготовить:** написать боту `/token` и держать под рукой два значения — адрес
(`https://casher-arx3.onrender.com/spend`) и личный токен.

Названия пунктов ниже даны как в русской локализации, в скобках — как в английской.

---

## Вариант A: простой (рекомендуется)

Сумму из текста пуша разбирает бот, на телефоне ничего парсить не нужно — меньше деталей,
меньше поводов сломаться.

1. Открыть **Быстрые команды** (Shortcuts) → нижняя вкладка **Автоматизация** (Automation) →
   **+** в правом верхнем углу → **Новая автоматизация** (New Automation).
2. Выбрать триггер **Когда я получаю уведомление** (When I Get a Notification). Он далеко
   в списке — проще найти поиском по слову `notification` или «уведомл».
3. **Приложение** (App) → выбрать приложение банка (Оптима).
4. Фильтр: **Сообщение** (Message) → **содержит** (Contains) → `Сумма:`

   Цепляться именно за `Сумма:`, а не за слово «Успещная». Опечатка в пуше — банковская,
   её могут исправить в любом обновлении приложения, и фильтр молча перестанет срабатывать.
5. Режим запуска: **Запускать сразу** (Run Immediately), переключатель
   **Уведомлять о запуске** (Notify When Run) — выключить. Тогда автоматизация отработает
   в фоне и на заблокированном экране, не отвлекая.
6. **Далее** (Next) → **Добавить действие** (Add Action) → найти
   **Получить содержимое URL** (Get Contents of URL) и настроить:
   - **URL**: `https://casher-arx3.onrender.com/spend`
   - развернуть **Подробнее** (Show More) → **Метод** (Method): `POST`
   - **Заголовки** (Headers) → добавить `X-Token` → вставить свой токен из `/token`
   - **Тело запроса** (Request Body): `JSON`
   - Добавить одно поле: ключ `raw`, тип **Текст** (Text), значение — переменная
     **Вход быстрой команды** (Shortcut Input), то есть текст уведомления.
7. Готово.

Бот сам достанет из текста сумму (`Сумма: 1470.00 KGS`) и валюту. Полный текст пуша при этом
сохраняется в базе — если банк поменяет формат, историю можно будет пересчитать.

## Вариант B: с разбором суммы на телефоне

Если хочется, чтобы сумму вычислял сам шорткат:

1. Шаги 1–5 те же.
2. Действие **Найти совпадение в тексте** (Match Text):
   - Текст: **Вход быстрой команды** (Shortcut Input)
   - Шаблон: `[\d\s]+\.\d{2}`
   - Если совпадений нет — движок регулярных выражений в Shortcuts свой, попробовать
     `[0-9]+\.[0-9][0-9]`
3. **Получить элемент из списка** (Get Item from List) → **Первый элемент** (First Item) →
   сохранить в переменную `Сумма`.
4. **Получить содержимое URL** (Get Contents of URL) — как в варианте A, но в теле JSON
   три поля:
   - `amount` (Текст) = переменная `Сумма`
   - `currency` (Текст) = `KGS`
   - `raw` (Текст) = **Вход быстрой команды** (Shortcut Input)

## Проверка без похода в магазин

С компьютера:

```bash
curl -X POST https://casher-arx3.onrender.com/spend \
  -H "X-Token: <твой токен>" \
  -H "Content-Type: application/json" \
  -d '{"raw": "Успещная операция по QR. Сумма: 1470.00 KGS"}'
```

В Телеграм должно прийти «💸 Новая трата: 1 470 KGS. Куда записать?» с кнопками. После нажатия
сообщение схлопнется в «✅ 1 470 KGS → Кафе».

Проверить сам шорткат: в приложении «Быстрые команды» открыть автоматизацию и нажать
**Запустить** — при ручном запуске входа-уведомления нет, поэтому бот ответит `400 no amount`.
Это нормально; настоящая проверка — реальная покупка или `curl` выше.

## Что учесть

- **Дубли.** Один платёж иногда даёт два пуша (например, ещё и на Apple Watch). Бот гасит
  повтор той же суммы в пределах 90 секунд.
- **Поступления и возвраты.** Под фильтр `Сумма:` попадёт и зачисление. Для таких записей есть
  кнопка **🚫 Не расход** — запись останется в истории, но в отчёты не попадёт.
- **Пропущенные вопросы.** Если не ответить на вопрос о категории, трата не теряется:
  команда `/pending` соберёт все неразмеченные.
- **Другие форматы пушей.** «Операция по QR» — только один сценарий; у оплаты картой и
  переводов текст свой. Собирай примеры по мере появления — правила фильтра уточним потом.
- **Токен.** Он равнозначен паролю: кто им владеет, тот пишет траты в твой аккаунт. Если
  утёк — `/newtoken` и вписать новый в шорткат.
